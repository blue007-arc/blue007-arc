I am a **Computer Science undergraduate (Class of 2027)** passionate about **AI Systems Engineering, Agentic Workflows, Distributed Systems, and Modern Full-Stack Development**. 

Instead of toy LLM wrappers, I focus on building **production-grade engineering systems**:
- 🛡️ **Autonomous Coding Agents** with human-in-the-loop gates and sandboxed execution.
- ⚡ **Fault-tolerant distributed workflows** using **Temporal.io** and vector databases.
- 📑 **Auditable full-stack data platforms** with pixel-level bounding-box citations and safe AST-validated SQL generation.
- 🧪 **Evaluation harnesses & arenas** benchmarking LLMs with deterministic unit test suites.
